Como Disponibilizar Este Sistema Sem Comprar Domínio

Opções 100% gratuitas e sem burocracia para colocar o portal em uso imediato na rede pública.

GitHub Pages

Permite hospedar este arquivo HTML gratuitamente na nuvem com link oficial acessível de qualquer lugar (ex: sua-secretaria.github.io/balcao).

  1. Crie uma conta no GitHub.
  2. Crie um repositório chamado balcao-escola.
  3. Envie este arquivo com o nome index.html.
  4. Ative o Pages nas configurações.
Recomendado para Redes Municipais
Rede Local ou Pen Drive

Não necessita de internet nem de servidor na web. O arquivo roda direto no navegador de qualquer computador da escola.

  1. Salve o arquivo index.html.
  2. Coloque numa pasta compartilhada da prefeitura ou num pen-drive.
  3. Dê dois cliques para abrir no Google Chrome ou Edge.
100% Offline e Imediato
Vercel ou Netlify

Plataformas modernas de hospedagem estática gratuita. Basta arrastar a pasta do computador para o site e o link estará pronto.

  1. Acesse vercel.com ou netlify.com.
  2. Faça um cadastro gratuito.
  3. Arraste o arquivo HTML para a área de upload.
  4. Seu site estará online em 10 segundos.
Arraste e Solte
Observação Técnica sobre Dados LocalStorage:

Este protótipo armazena os dados localmente no navegador (`localStorage`). Para integrar o sistema entre múltiplos computadores em tempo real, basta posteriormente conectar este código a um banco de dados em nuvem gratuito (como Firebase ou Supabase) sem necessidade de alterar o design visual.
